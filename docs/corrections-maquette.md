# Écarts de la maquette Base44 à corriger dans la V1

La maquette (https://daily-edge-pro.base44.app/) a été validée telle quelle le 19 novembre 2026, avec ces écarts connus à ne pas reproduire.

## Écran de présentation 1/3 (/intro)

- [ ] Dans la carte « Principe du jour », le résumé affiché (« Si une tâche prend moins de deux minutes, fais-la tout de suite. ») est la règle de David Allen, pas celle de James Clear. Utiliser le résumé du catalogue pour P026 : « Réduire une habitude à une version de deux minutes pour commencer sans effort. » (EN : « Scale a habit down to a two-minute version so starting takes no effort. »). Idéalement, lire ce texte depuis le catalogue plutôt que l'écrire en dur.
- [ ] Sous le titre « Un principe par jour, tiré des meilleurs livres. », remettre le texte : « Hill, Kiyosaki, Clear, Covey… 115 principes reformulés en trois lignes, choisis pour ton objectif. » (le nombre peut venir du catalogue).
